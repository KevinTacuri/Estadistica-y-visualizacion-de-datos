# Estadistica-y-visualizacion-de-datos

## Visualización de datos con Matplotlib

### Descripción

Proyecto práctico enfocado en la visualización de datos utilizando la librería Matplotlib de Python. Se exploran diferentes tipos de gráficos y su aplicación para representar información de manera clara y facilitar la interpretación de los datos.

### Objetivos

- Conocer las principales funcionalidades de Matplotlib.
- Crear diferentes tipos de visualizaciones utilizando Python.
- Representar tendencias, comparaciones y distribuciones de datos.
- Seleccionar diferentes tipos de gráficos según la información que se desea analizar.
- Interpretar visualmente los resultados obtenidos.
- Visualizaciones desarrolladas

El proyecto incluye ejemplos prácticos de:

Gráficos de líneas: representación de tendencias y cambios.
Gráficos de áreas: visualización de variaciones y acumulaciones.
Gráficos de barras: comparación entre diferentes categorías.
Histogramas: análisis de la distribución de los datos.

### Tecnologías y herramientas

- Python
- Matplotlib
- Jupyter Notebook

### Aprendizajes

Este proyecto permitió fortalecer conocimientos de visualización de datos con Python y comprender cómo diferentes representaciones gráficas pueden facilitar el análisis y la comunicación de información.
